# Battle Master — The Bell Marches

A standalone mobile-landscape roguelike card game. The supplied 26 November 2026 design plan is the gameplay reference. Yuddh is a read-only architecture and presentation reference; no changes to that repository.

The initial implementation targets the browser with an independent deterministic JavaScript engine and an Android wrapper planned for later. This deliberately follows Yuddh's web-first direction rather than the PDF's Unity proposal. See the phase roadmap for implementation and validation status.
